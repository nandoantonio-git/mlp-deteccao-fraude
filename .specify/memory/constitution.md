# Constitution — CP4 Detecção de Fraude em Cartão de Crédito

## Scope Discipline

This project is an academic machine learning delivery optimized for complete, reproducible evaluation. It must not expand into production antifraud operations, cloud deployment, authentication, frontend work, automated retraining, or monitoring unless explicitly re-scoped.

## Evaluation Evidence First

Every major claim must be backed by reproducible artifacts: dataset exploration, tracked experiments, comparable metrics, selected model justification, local prediction demonstration, and clear execution instructions.

## Honest Imbalanced Classification

Model quality must be judged primarily on fraud-class recall, precision, F1-score, and overall separability. Accuracy alone is not acceptable evidence because the dataset is highly imbalanced.

## Reproducibility and Consistency

The delivery must use fixed randomness, a reusable preprocessing path, a clean repository, and instructions that allow another evaluator to reproduce the workflow locally. Training, experiment tracking, model promotion, and prediction must use consistent data transformations.

## Academic Acceptance Requirements

A notebook is mandatory as EDA evidence. The repository must also include scripts or equivalent reproducible commands for training, experiment comparison, model selection, and local prediction testing.
